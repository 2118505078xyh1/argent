Rust · single binary · provider agnostic

A coding agent that fits in one process.

TUI, Tauri desktop, RPC, HTTP/SSE, ACP, MCP, LSP and workspace tools. One Rust runtime; no Node.

Build from source Windows releases

Small runtime

Release binaries are about 5.4 MB (CLI) and 10 MB (desktop). The CLI path starts in tens of milliseconds and never starts a browser engine; the desktop shell uses the system WebView.

Anchored edits

read hash=true emits LINE#HASH anchors. edit accepts one range or a multi-file edits batch, rejects stale anchors, and preserves CRLF/BOM. An optional apply_patch plugin accepts Codex/OpenCode envelopes.

Local by default

Anthropic, OpenAI-compatible and local providers; API keys, OAuth, keyring, signed update manifests and local audit logs. No hosted control plane required.

Built for automation

One-shot JSONL, RPC, SSE server, ACP, background jobs, workflow DAGs, checkpoints and /rewind.

Install

From source (Rust 1.85+):

git clone https://github.com/2118505078xyh1/argent
cd argent
cargo build --release -p argent-cli
./target/release/argent --help

Or download the latest Windows bundle from GitHub Releases.

Run

argent doctor
argent login
argent "summarize this repository"
argent --mode plan "add an integration test for session import"
argent --serve --serve-port 8787

Press Shift+Tab in the TUI to toggle plan mode; /help lists commands.
